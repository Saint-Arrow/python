# CIFAR-10 彩色图像分类 Demo

## 项目简介

基于 PyTorch 的 CIFAR-10 彩色图像分类课程 demo，使用经典 CNN（LeNet-5 变体）完成 **10 类彩色物体** 的训练与推理。

## CIFAR-10 数据集

CIFAR-10 共 60000 张 32×32 彩色图像，分为 10 个类别：

| 编号 | 英文 | 中文 | 示例说明 |
|:---:|------|------|---------|
| 0 | airplane | 飞机 | 客机、战斗机等 |
| 1 | automobile | 汽车 | 轿车、SUV 等 |
| 2 | bird | 鸟 | 各种鸟类 |
| 3 | cat | 猫 | 家猫等 |
| 4 | deer | 鹿 | 各种鹿类 |
| 5 | dog | 狗 | 各种犬类 |
| 6 | frog | 青蛙 | 蛙类 |
| 7 | horse | 马 | 各种马类 |
| 8 | ship | 船 | 轮船、帆船等 |
| 9 | truck | 卡车 | 货车、皮卡等 |

- **训练集**：50000 张（每类 5000 张）
- **测试集**：10000 张（每类 1000 张）

## 模型结构

采用 LeNet-5 风格的 CNN，结构如下：

```
输入 (3×32×32)
  → Conv2d(3→6, 5×5) → ReLU → MaxPool(2×2)   # 输出: 6×14×14
  → Conv2d(6→16, 5×5) → ReLU → MaxPool(2×2)   # 输出: 16×5×5
  → Flatten (16×5×5 = 400)
  → Linear(400→120) → ReLU
  → Linear(120→84)  → ReLU
  → Linear(84→10)                               # 10 类输出
```

- **损失函数**：`CrossEntropyLoss`（内部包含 Softmax，适用于多分类）
- **优化器**：SGD

## 文件说明

| 文件 | 说明 |
|------|------|
| `training_cifar10_v0.py` | 训练脚本：下载数据、定义模型、训练、测试、保存模型 |
| `detect_v0.py` | 推理脚本：加载模型，对自定义 32×32 彩色图片进行推理 |
| `cifar10.pth` | 训练好的模型权重文件 |
| `car.png` | 示例推理图片（汽车） |
| `data/` | CIFAR-10 数据集存放目录 |

## 快速开始

### 1. 训练

```bash
python training_cifar10_v0.py
```

- 首次运行需下载数据集，可将 `download_data` 改为 `False` 并手动将数据放入 `data/` 目录
- 具体超参数（学习率、epoch、batch_size 等）见脚本内注释
- 训练完成后自动在测试集上评估准确率，并保存模型到 `cifar10.pth`

### 2. 推理

```bash
python detect_v0.py car.png
```

**参数说明：**

| 参数 | 说明 |
|------|------|
| `<图片路径>` | 必填，待推理的 32×32 彩色图片路径 |
| `--inv` | 可选，对图片像素取反 |
| `--thr N` | 可选，启用二值化，阈值 N（>N→255, ≤N→0） |

**输出示例：**

```
已加载模型: ...\cifar10.pth
图片: car.png
推理结果: 1（置信度: 89.3%）
概率分布: {0: '1.2%', 1: '89.3%', 2: '0.5%', ...}
```

## 注意事项

1. 推理图片尺寸必须为 **32×32**（与训练数据一致）
2. 推理图片需为 **彩色图**（3 通道），与 MNIST 灰度图不同
3. 数据预处理流程：像素值 0-255 → 缩放到 0-1 → 归一化到 [-1, 1]
