 
## 目的
分析逻辑分析仪导出来的数据，提取出高电平的持续时间，找出持续时间比如在500us-1ms之间的数值

### 文件txt数据格式
```
 0.41239648, 1
 0.44491378, 0
 0.44578522, 1
 0.47829719, 0
```
其中第一列是时间，第2列是值   
另外文件第一行不需要处理，不是有效数据  
操作的文件为单前目录下的txt文件，只需要处理第一个发现的txt文件即可

### 数据计算
高电平持续时间计算方式为   
value=1的所在行的时间为开始时间记为T0   
下一行value变成0的所在行的时间记为T1   
那这个高电平的持续时间为T1-T0   
此时打印该持续时间

### 数据过滤
针对上面计算出来的时间进行判断，如果时间满足过滤条件，如500us-1ms，那就打印这个匹配到的时间以及文本所在的行所有内容  

### 参数输入
匹配的时间的最小值以及最大值，默认为0.0005/0.001,输入格式也是类似这个小数点值，以s为单位
